# Zonaris

Portal oficial estatico del universo narrativo Zonaris.

El proyecto esta construido con HTML5, CSS3 y JavaScript Vanilla. No usa backend, CMS, frameworks ni dependencias externas.

## Objetivo

Diseñar el portal oficial de un universo narrativo, no la pagina promocional de una novela.

## Secciones

- Inicio
- Libros
- Mundo
- Autor
- Galeria
- Contacto

## Probar en local

Abrir `index.html` directamente funciona para una revision rapida. Para probar rutas como `/libros/`, usar:

```bash
npm run start
```

La URL local por defecto es:

```text
http://localhost:4173
```
